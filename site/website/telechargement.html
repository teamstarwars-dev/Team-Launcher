Installation en 3 étapes

  1. Télécharge le fichier ci-dessus (c'est la version la plus complète, donc la plus lourde : elle contient tout ce qu'il faut pour démarrer sur n'importe quel PC).
  2. Lance TeamLauncher.exe. Windows peut afficher un avertissement SmartScreen les premiers jours : clique sur « Informations complémentaires » → « Exécuter quand même ».
  3. Connecte-toi avec ton compte Microsoft officiel (ou choisis le mode hors-ligne), crée une instance, et c'est parti.

Questions fréquentes

Pourquoi si léger ?

C'est un launcher classique : il utilise le .NET 8 Desktop Runtime déjà présent sur la plupart des PC Windows. S'il n'est pas installé, le launcher te le dira au démarrage avec un lien pour le télécharger. C'est rapide à installer (30 secondes).

Mon antivirus s'affole, pourquoi ?

Les launchers touchent aux fichiers du jeu et au réseau : certains antivirus sont méfiants par défaut. Ajoute simplement une exclusion pour le dossier de Team Launcher. Le launcher ne collecte aucune donnée.

Est-ce que ça marche avec mon compte cracké ?

Non. Team Launcher utilise uniquement la connexion Microsoft officielle (ou un mode hors-ligne limité au solo). Il ne contourne jamais les serveurs d'authentification.
