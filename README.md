# Team Launcher

Launcher Minecraft léger, rapide et sans pub : instances, mods Modrinth et CurseForge, serveurs, skins.

Ce dépôt sert uniquement à distribuer les versions publiées. Le code source n'est pas public.

## Télécharger

- **Site officiel** : https://team-launcher.pixelhorizons.fr
- **Versions** : onglet [Releases](../../releases) de ce dépôt (Windows, Linux, Mac à puce Apple).

Le launcher se met ensuite à jour tout seul.
